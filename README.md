# Satisfactory Companion

Offline Satisfactory production calculator, recipes, railroad signal planner, and tips.

A single-page companion for planning factory production chains in [Satisfactory](https://www.satisfactorygame.com/). Works fully offline in the browser—no server required.

## Features

- Production calculator / recipe planner with flowchart view
- Alternate-recipe picker for the current chain
- Recipe browser and tips
- Railroad signal planner (edit, validate, simulate trains)
- Data from Satisfactory 1.0

## Data & credits

Item and recipe data is derived from [SatisfactoryTools](https://github.com/greeny/SatisfactoryTools) (MIT license) and Satisfactory 1.0 game data. Fan-made; not affiliated with Coffee Stain Studios. No official game art is included.
