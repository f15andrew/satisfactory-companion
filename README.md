# Satisfactory Companion

Offline Satisfactory production calculator, recipes, and tips.

A single-page companion for planning factory production chains in [Satisfactory](https://www.satisfactorygame.com/). Works fully offline in the browser—no server required.

## Features

- Production calculator / recipe planner
- Recipe browser and tips
- Data from Satisfactory 1.0

## Data & credits

Item and recipe data is derived from [SatisfactoryTools](https://github.com/greeny/SatisfactoryTools) (MIT license) and Satisfactory 1.0 game data.
